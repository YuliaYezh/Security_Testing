# Часть 2: Активное сканирование

## Цель работы
Провести активное сканирование трёх веб-ресурсов (`1111.ru`, `222.ru`, `3333.ru`) для определения:
- открытых портов и работающих сервисов;
- версий программного обеспечения;
- операционной системы (по возможности);
- использования защитных механизмов.

## Инструменты и флаги
- **nmap** – основной сканер.
  - `-sS` – скрытое SYN-сканирование.
  - `-sV` – определение версий сервисов.
  - `-O` – определение ОС.
  - `-A` – расширенное сканирование (включает `-sV`, `-sC`, `-O`).
  - `-T2` – умеренная скорость (для снижения нагрузки).

## Ход работы

### 1. Сканирование `1111.ru`

Порт	Протокол	Сервис	Версия
53	TCP	DNS	bind
80	TCP	HTTP	nginx 1.14.1
443	TCP	HTTPS	nginx 1.14.1
ОС: не определена (возможно, из-за настроек файрвола или DDoS-защиты).

Дополнительно: на порту 443 присутствует SSL-сертификат.

### 2. Сканирование `2222.ru`

Порт	Протокол	Сервис	Версия
80	TCP	HTTP	nginx 1.14.1
443	TCP	HTTPS	nginx 1.14.1
Версия PHP: 7.4.12 (получено из заголовков).

Другие порты не обнаружены.

### 3. Сканирование `3333.ru`

Сканирование не выявило открытых портов (все фильтруются).

Вероятно, ресурс скрыт за системой защиты от DDoS-атак или доступен только по HTTPS с нестандартным портом (требуется дополнительная разведка).

Выводы
Основной домен 1111.ru предоставляет наибольший объём информации: открытый DNS, веб-сервер с явными версиями.

2222.ru показывает только веб-порты, что характерно для образовательного портала.

3333.ru защищён лучше – прямое сканирование не даёт результатов, что усложняет сбор информации.
